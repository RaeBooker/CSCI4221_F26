So catching up with my team I was able to get two of our user stories that we needed in order to make sure that our project looks to its perfection.
The first one is 
 User Story 1: Reliable two-way conversion
**As a** student, **I want to** convert between decimal numbers and Roman numerals **so that** I can check my work in either format.  
**Acceptance criteria:** `2026 → MMXXVI`, `CMXCIX → 999`, and the appropriate action determines which conversion is performed. Supported values are whole numbers 1 through 3999.

The second one is that
Validation instead of incorrect output
**As an** instructor, **I want to** be told when a value is invalid **so that** I do not teach or rely on a wrong conversion.  
**Acceptance criteria:** The app rejects `VX`, `IIII`, `0`, and `4000`; it displays a readable explanation; it does not leave an old answer visible as though it belongs to the new input.
